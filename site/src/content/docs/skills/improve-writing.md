---
title: improve-writing
description: Refine, tighten, restructure, or finish an existing draft that already has structure.
---

Takes a draft that already has some structure and makes it stronger. The skill that actually changes
the text in [Review](/online-writing-skills/guides/review/).

## When to use it

When you have an existing draft with some structure already in place — headers, partial sections,
framework annotations, or a clear direction — and want it refined, tightened, restructured, or
finished. Signals: the draft feels flat or rough, sections trail off mid-thought, or you can't name
what's wrong but know it isn't ready.

## When not to use it

- For raw, unstructured input → use [`create-post`](/online-writing-skills/skills/create-post/) / [`create-draft`](/online-writing-skills/skills/create-draft/).
- For rating a finished piece → use [`rate`](/online-writing-skills/skills/rate/).

## Works well with

Run [`diagnose`](/online-writing-skills/skills/diagnose/) first to find the issues, then point this
skill at them; re-check with [`rate`](/online-writing-skills/skills/rate/).

## Example

```text
Improve this draft, focusing on the issues diagnose found.
```
