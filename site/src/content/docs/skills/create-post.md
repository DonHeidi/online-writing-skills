Finds the structure hiding inside stream-of-consciousness input and shapes it into a short-form post.
Part of [Production](/online-writing-skills/guides/production/).

## When to use it

When you have raw, unstructured material (brain dump, notes, bullet points, stream-of-consciousness)
and want it shaped into a publishable **short-form post in the 800–1,200 word range** — social,
LinkedIn-length, or short blog.

## When not to use it

- Long-form (2,500–3,000 words) → use [`create-draft`](/online-writing-skills/skills/create-draft/).
- Platform micro-posts (X / Threads / Bluesky) → use [`distill`](/online-writing-skills/skills/distill/).
- An existing draft that already has structure → use [`improve-writing`](/online-writing-skills/skills/improve-writing/).

## Reads

`purpose.md`, `expertise.md`, `buckets.md`, and `tonality.md` — applies your voice profile and the
structural frameworks, and finds the structure in *your* thinking rather than inventing arguments.

## Example

```text
Turn these notes into a short-form post (use create-post): <raw material>.
```
