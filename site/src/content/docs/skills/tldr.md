Produces a one-paragraph abstract for the top of a long piece. Part of
[Review](/online-writing-skills/guides/review/).

## When to use it

When you have a long-form article (typically 2,500–3,000 words) and want a single-paragraph abstract
for the top of the piece. Triggers: "tldr", "abstract this", "write an abstract for", "synopsis of
this draft", "summarize this article".

It produces **~100–150 words** in a neutral synthesis register, in your voice and the source's
register — a hybrid academic abstract / synopsis that lets a reader decide whether to commit to the
full piece.

## When not to use it

- For distilling into multiple shorter posts → use [`distill`](/online-writing-skills/skills/distill/).
- For rating quality → use [`rate`](/online-writing-skills/skills/rate/).
- For headlines → use [`headlines`](/online-writing-skills/skills/headlines/).

## Example

```text
Write a TLDR for the top of this article.
```
